# 🔎 Taller #1 (Libreta de calificaciones)
** 🗓️ Fecha:** 14/09/2026

## 📖 Contenido del repositorio
Salida por consola que permite almacenar datos de manera repetitiva hasta cumplir una condición.

EjemploWhile: Bucle while básico que no es interrumpido hasta completar una condición definida por una cantidad en el código fuente.

EjemploWhile2: Bucle while capaz de ser interrumpido al insertar un carácter detectable por las condicionales del código fuente.

## 💻 Tecnologías
C#, Visual Studio.
Autor: Rómel Tadeo Rodríguez González
